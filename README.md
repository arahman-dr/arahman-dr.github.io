# arahman-dr.github.io

Personal website of Md Abdur Rahman, served by GitHub Pages.

## Changing the content

All the text lives in **`content.js`**. You never need to touch the HTML.

- **Easiest:** open `https://arahman-dr.github.io/edit.html`, edit with the forms, click **Download content.js**, and upload that file here (Add file > Upload files > Commit changes).
- **Directly:** click `content.js` on GitHub, then the pencil icon. Each section starts with a short note explaining it.
- **Hide something without deleting it:** add `hide: true` to its block.
- **Photos:** upload to the `images` folder, then use the path, e.g. `images/girona-1.jpg`.
- **A typo breaks nothing for long:** the site shows a red box with the line number of the problem.

## Files

| File | What it is | Edit it? |
|---|---|---|
| `content.js` | All text, lists and links | Yes |
| `edit.html` | The form editor | No |
| `images/` | Your photos and PDFs | Add files |
| `*.html` | Empty page shells | No |
| `assets/site.js` | Builds the pages from content.js | No |
| `assets/style.css` | Design | Only to restyle |
| `assets/map.js`, `assets/world.js` | Map outlines (Natural Earth) | No |
| `assets/editor.js`, `assets/editor.css` | The editor | No |
