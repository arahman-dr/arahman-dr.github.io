Edit my website

Change anything below, then download the file and upload it to GitHub. Your edits are kept in this browser until you do.

How to put your changes online
  1. Click Download content.js.
  2. Open your repository on GitHub, arahman-dr/arahman-dr.github.io.
  3. Click Add file, then Upload files, and drop the downloaded content.js there. GitHub replaces the old file.
  4. Click Commit changes. The site updates within a minute or two.

Photos: upload them to the images folder the same way, then write their path here, for example images/girona-1.jpg.

Another way: open content.js on GitHub, click the pencil icon, select all the text, paste what Copy file text gave you, and commit.
